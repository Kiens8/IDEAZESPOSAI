# API Reference

IDEAZES POS AI provides a RESTful API for building custom customer order apps and integrations.

## Base URL

```
Production: https://api.ideazes.com
```

## Authentication

The API uses API key authentication. Include your API key in the `X-API-Key` header.

### API Keys

| Key Type | Purpose | Access Level |
|----------|---------|--------------|
| Customer Key | Customer Order App | Customer-facing endpoints only |
| External Key | External Developers | Customer-facing endpoints + rate limited |

### Using Your API Key

```bash
curl -X GET "https://api.ideazes.com/api/endpoint" \
  -H "X-API-Key: your_api_key_here"
```

## Rate Limits

| Key Type | Requests/minute |
|----------|-----------------|
| Customer Key | Unlimited |
| External Key | 100 |

## Response Format

All responses are in JSON format with appropriate HTTP status codes.

### Success Response
```json
{
  "key": "value"
}
```

### Error Response
```json
{
  "detail": "Error message description"
}
```

## Customer App Endpoints

These endpoints are designed for **Customer Order Apps**. Use these to build your own ordering system.

### Getting Started

To build a customer order app, you need:

1. **Settings** - Get restaurant info and features
2. **Menu** - Display menu items and categories
3. **Tables** - Table lookup via QR code
4. **Orders** - Create and manage orders
5. **Loyalty** - Customer registration and login
6. **Vouchers** - Validate and redeem vouchers

### Settings

#### Get Customer Settings

Get public settings for an outlet.

```
GET /api/customer/settings/{outlet_id}
```

**Response:**
```json
{
  "customer_id": 1,
  "restaurant_name": "Kens Restaurant",
  "restaurant_logo": "https://...",
  "timezone": "Asia/Kuala_Lumpur",
  "customer_registration_enabled": true,
  "loyalty_program_enabled": true,
  "vouchers_enabled": true,
  "welcome_voucher_enabled": true
}
```

#### Get Order Settings

Get order-related settings (payment methods, tax, etc.).

```
GET /api/orders/settings/{outlet_id}
```

**Response:**
```json
{
  "allow_dine_in": true,
  "allow_takeaway": true,
  "allow_delivery": false,
  "payment_methods": ["cash", "card", "ewallet"],
  "currency_symbol": "RM",
  "currency_code": "MYR",
  "tax_enabled": true,
  "tax_rate": 6,
  "tax_inclusive": false,
  "order_prefix": "ORD",
  "split_bill_enabled": true,
  "table_required": true
}
```

### Orders

#### Create Order

```
POST /api/orders/
Content-Type: application/json

{
  "outlet_id": 1,
  "order_type": "dine_in",
  "table_id": 1,
  "dining_customer_id": 7,
  "items": [
    {
      "menu_item_id": 1,
      "quantity": 2,
      "unit_price": 12.90,
      "notes": "Less spicy"
    }
  ]
}
```

**Response:**
```json
{
  "id": 123,
  "order_number": "ORD-20261006-0001",
  "status": "pending",
  "total": 25.80
}
```

#### Get Orders

```
GET /api/orders/?outlet_id={outlet_id}
```

#### Get Active Orders

```
GET /api/orders/active?outlet_id={outlet_id}
```

#### Get Order by Number

```
GET /api/orders/number/{order_number}
```

#### Update Order Status

```
PATCH /api/orders/{order_id}/status
Content-Type: application/json

{
  "status": "ready"
}
```

#### Cancel Order

```
PATCH /api/orders/{order_id}/cancel
```

## Geocoding (Competitor Discovery)

### Geocode Address

Convert address text to coordinates.

```
GET /api/competitors/geo-code?text=Kuala Lumpur
```

### Reverse Geocode

Convert coordinates to address.

```
GET /api/competitors/geo-code?lat=3.1856&lng=101.5979
```

**Response:**
```json
{
  "results": [
    {
      "lat": 3.1856,
      "lng": 101.5979,
      "formatted": "Kuala Lumpur, Malaysia",
      "name": "Kuala Lumpur"
    }
  ]
}
```

### Discover Nearby Places

Find restaurants near a location.

```
POST /api/competitors/discover-places
Content-Type: application/json

{
  "lat": 3.1856,
  "lng": 101.5979,
  "radius_km": 5
}
```

|------|-------------|

## Build Your Customer Order App

### Quick Start Example

```javascript
// 1. Get outlet settings (includes customer_id for further calls)
const settingsRes = await fetch('https://api.ideazes.com/api/customer/settings/1');
const settings = await settingsRes.json();
console.log('Restaurant:', settings.restaurant_name);

// 2. Get menu items
const menuRes = await fetch('https://api.ideazes.com/api/menu/items?outlet_id=1');
const menuItems = await menuRes.json();

// 3. Get walk-in customer ID (for anonymous orders)
const walkinRes = await fetch(`https://api.ideazes.com/api/loyalty/walkin-customer/${settings.customer_id}`);
const walkin = await walkinRes.json();

// 4. Create order
const orderRes = await fetch('https://api.ideazes.com/api/orders/', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    outlet_id: 1,
    order_type: 'dine_in',
    table_id: selectedTable.id,
    dining_customer_id: walkin.id,  // Use walk-in customer
    items: [
      { menu_item_id: 1, quantity: 2, unit_price: 12.90 }
    ]
  })
});
const order = await orderRes.json();
console.log('Order created:', order.order_number);
```

### Customer Login Flow

```javascript
// 1. Register new customer
await fetch('https://api.ideazes.com/api/loyalty/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    customer_id: 1,
    name: 'John Doe',
    email: 'john@example.com',
    phone: '60123456789'
  })
});

// 2. Login
const loginRes = await fetch('https://api.ideazes.com/api/loyalty/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    customer_id: 1,
    phone: '60123456789'
  })
});
const customer = await loginRes.json();
// Save customer.id for future requests
```
