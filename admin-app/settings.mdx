# Admin Settings

The Admin Settings page allows internal staff to configure system-wide settings that control payment and subscription behavior. Access the Settings page at **admin.ideazes.com/settings**.

---

## Accessing Settings

1. Login to **admin.ideazes.com**
2. Navigate to **Settings** in the sidebar menu
3. View and modify system configuration values

---

## Configurable Settings

| Setting Key | Default | Description |
|------------|---------|-------------|
| `payment_due_days` | 14 | Payment due in days for Pay Later invoices |
| `trial_days` | 30 | Trial period in days |
| `overdue_warning_days` | 7 | Days before due date to show payment warning |

---

## Settings Details

### Payment Due Days (payment_due_days)

**Purpose:** Controls how many days customers have to pay for Pay Later invoices.

**Affected Areas:**
- Invoice `due_date` calculation
- Stripe Invoice `days_until_due` parameter
- Subscription `payment_due_date` field

**Formula:**
```
invoice.due_date = invoice_created_date + payment_due_days
```

**Example:**
- Payment Due Days = 14
- Invoice created on Jan 1
- Invoice due on Jan 15

---

### Trial Days (trial_days)

**Purpose:** Controls the length of trial period for new trial subscriptions.

**Affected Areas:**
- `trial_ends_at` date calculation when creating trial subscriptions

**Formula:**
```
trial_ends_at = subscription_created_date + trial_days
```

**Example:**
- Trial Days = 30
- Subscription created on Jan 1
- Trial ends on Jan 31

---

### Warning Days (overdue_warning_days)

**Purpose:** Controls when users see payment reminder warnings during POS login.

**Affected Areas:**
- Login access control warnings
- Payment reminder display

**Formula:**
```
if (due_date - today) <= warning_days:
    show_payment_warning()
```

**Example:**
- Warning Days = 7
- Payment due on Jan 15
- Warning shown starting Jan 8

---

## Important Notes

### Impact on Existing Subscriptions

⚠️ **Changes only affect NEW subscriptions/invoices**

| Setting | Impact |
|---------|--------|
| `payment_due_days` | New subscriptions only - existing keep original dates |
| `trial_days` | New trial subscriptions only |
| `overdue_warning_days` | All login checks immediately |

**Safe to modify anytime** - existing customers are not affected.

---

### How Settings Work Together

```
New Pay Later Subscription Created
    ↓
Check payment_due_days setting
    ↓
Set invoice.due_date = today + payment_due_days
    ↓
Set subscription.payment_due_date = today + payment_due_days
```

## Database Schema

Settings are stored in the `settings` table in the Website API database:

```sql
CREATE TABLE settings (
    key TEXT PRIMARY KEY,
    value TEXT NOT NULL,
    description TEXT,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## API Endpoints

Settings can also be managed via API:

```bash
# Get all settings
GET /api/admin/settings

# Get specific setting
GET /api/admin/settings/{key}

# Update a setting
PUT /api/admin/settings/{key}
Body: {"value": "30"}
```
