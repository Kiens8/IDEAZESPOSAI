# AI Chatbot Module

## Overview

The AI Chatbot module provides intelligent customer and staff assistance within the POS system. It supports multiple languages, custom greetings, and configurable behavior.

## Features

- **Multi-language Support**: English, Chinese, Malay, Khmer, Multilingual
- **Custom Bot Identity**: Configurable bot name and greeting message
- **Enable/Disable Control**: Toggle chatbot availability per outlet
- **Role-based Responses**: Different behavior for customer, staff, manager, admin
- **Intent-based Processing**: Recognizes orders, menu requests, reservations, etc.
- **AI Fallback**: Uses MiniMax for complex queries (admin mode)

## Settings

### Configuration Fields

| Setting | Key | Description | Default |
|--------|-----|-------------|---------|
| Enable AI Chatbot | `ai_enabled` | Toggle chatbot availability | `true` |
| Bot Name | `bot_name` | Display name for chatbot | `"Lumi"` |
| Bot Language | `bot_language` | Response language code | `"en"` |
| Auto-Response Greeting | `bot_greeting` | Custom welcome message | `null` |

### Language Options

| Code | Language | Description |
|------|----------|-------------|
| `en` | English | Default English responses |
| `zh` | Chinese | Simplified Chinese (中文) |
| `ms` | Malay | Bahasa Melayu |
| `kh` | Khmer | ភាសាខ្មែរ |
| `multi` | Multilingual | Mixed language responses |

## API Endpoints

### POST /api/chatbot/

Send a message to the chatbot.

**Request Body:**
```json
{
  "message": "string",           // User message
  "chatbot_type": "string",     // "customer", "staff", "manager", "admin"
  "outlet_id": "number",        // Outlet ID for settings lookup
  "language": "string"          // Language code (optional, overrides settings)
}
```

**Response:**
```json
{
  "intent": "string",           // Detected intent
  "response": "string",         // Bot response text
  "action": "string|null",      // Optional action hint
  "data": "object|null"        // Optional additional data
}
```

**Error Responses:**
- `403`: Chatbot is disabled for this outlet

### GET /api/chatbot/test

Test endpoint to verify chatbot is running.

### Basic Intents

| Intent | Patterns | Description |
|--------|----------|-------------|
| `greeting` | hi, hello, hey | Welcome message |
| `thanks` | thank you, thanks | Acknowledgment |
| `bye` | goodbye, bye | Farewell |
| `help` | help, what can you do | Help information |

### Order Intents

| Intent | Patterns | Description |
|--------|----------|-------------|
| `order` | i want to order, place order | Order placement |
| `menu` | menu, what's available | Menu display |
| `status` | order status, where's my food | Order tracking |
| `payment` | pay, how to pay | Payment info |

### Restaurant Operations (Staff+)

| Intent | Patterns | Description |
|--------|----------|-------------|
| `sales` | today's sales, revenue | Sales reports |
| `tables_served` | tables served, occupied | Table status |
| `pending_orders` | pending orders | Kitchen queue |
| `kitchen_status` | orders in kitchen | Kitchen display |
| `ready_orders` | ready orders | Pickup queue |
