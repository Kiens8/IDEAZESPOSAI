# Proposed UI Changes for Renewal System

> **Date:** September 22, 2026
> **Status:** Proposed

This document outlines UI changes needed to align customer-facing pages with the latest [Renewal System](./renewal-system) documentation.

---

## Overview

| Page | Current State | Changes Needed |
|------|--------------|----------------|
| Signup Page | Basic trial signup | Add billing cycle selection + payment method for trial AND free plan |
| Customer Portal | Shows subscription/invoices | Add trial/free plan-specific displays, upgrade flow |
| Invoice Detail | Generic invoice display | Show trial/free plan badge, clarify $0 auto-paid |
| Admin: Subscriptions | List subscriptions | Add trial status filtering, trial_ends_at column |
| Admin: Invoices | List invoices | Show invoice type (trial/free/paid/renewal) |

**Note:** Free Plan ($0) now follows the same flow as Trial:
- Payment method required (for future upgrades)
- Invoice created with $0, status = pending
- Cron job auto-marks as paid

---

## 1. Signup Page (`site/src/app/signup/page.tsx`)

### Current Behavior
- Simple signup with plan selection
- Trial option available but basic

### Required Changes

#### 1.1 Add Billing Cycle + Payment Method for Trial AND Free Plan

**Current:** Customer selects plan → starts trial → no payment info collected

**Required (for BOTH Trial AND Free Plan):**
1. Customer selects plan
2. **NEW:** Select billing cycle (monthly/annual) — required for future billing
3. **NEW:** Select payment method — required even for $0 plans (credit card stored for future upgrades)
4. Start subscription with $0

**Important:** Free Plan ($0) now follows the same flow as Trial:
- Payment method required (stored for future billing)
- Invoice created with $0, status = pending
- Cron job auto-marks as paid

**UI Mockup:**
```
┌─────────────────────────────────────────┐
│  Start Your 30-Day Free Trial           │
├─────────────────────────────────────────┤
│  Select Plan:  [Starter] [Basic] [Pro]  │
│                                         │
│  Billing Cycle:  ○ Monthly  ● Annual     │
│                                         │
│  Payment Method:                         │
│    ○ Credit Card (Visa ****4242)         │
│    ○ Pay Later                          │
│                                         │
│  [Start Free Trial]                     │
│                                         │
│  ✓ No payment required now              │
│  ✓ Your card will be charged on         │
│    Day 30 when trial ends               │
└─────────────────────────────────────────┘
```

#### 1.2 Display Trial Information Clearly

**Add to signup confirmation:**
- Trial period: 30 days
- What happens at Day 30
- Payment will be charged to selected method
- Cancel anytime before Day 30 = no charge

#### 3.2 Invoice Description Labels

| Invoice Type | Description Format | Display |
|-------------|-------------------|---------|
| Trial | "Trial Period - 30 days" | 🎁 Trial Period |

| Renewal | "Recurring subscription - monthly" | Renewal |

| Status | Current Display | New Display |

| paid | Paid | ✅ Paid on [date] |
| forgiven | (show as pending) | ❌ Waived / Not Paid |
