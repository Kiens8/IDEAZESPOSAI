# Proposed Changes to Align with Renewal System

This document outlines changes needed to sync the implementation with the latest [Renewal System](./renewal-system) documentation.

> **Note:** Existing code that no longer aligns with the new design will be **commented out** or marked as deprecated.

---

## Overview

| Item | Current Behavior | New Behavior | Action |
|------|-----------------|--------------|--------|
| Period Extension on Payment | Extends on payment received | Period end stays fixed | ✅ DONE |
| Invoice Generation at Renewal | Via Stripe webhook | Via cron job (for pay-later) | ✅ DONE |
| Billing Cycle Change monthly→annual | period_end recalculated | period_end unchanged | ✅ DONE |
| Billing Cycle Change annual→monthly | Blocked | Uses next_billing_cycle at renewal | ✅ DONE |

---

## Completed Changes

### ✅ 1. Period Extension on Payment - COMMENTED OUT

**File:** `website_api/app/routes/webhooks.py`

The `extend_subscription_period` function is now commented out per design:
> "Payment extends nothing - Period end date stays fixed"

---

### ✅ 2. Cron Job: Generate New Invoice at Period End

**File:** `website_api/scripts/send_notifications.py`

Function `generate_renewal_invoices()` is now implemented:
- Creates new invoice at period end
- Sets `due_date = period_end + grace_period (14 days)`
- Subscription continues as active
- Handles both monthly and annual billing cycles

---

### ✅ 4. Billing Cycle Change: monthly → annual (period_end unchanged)

**File:** `website_api/app/routes/subscription.py`

**Before (WRONG):**
```python
# Recalculate period_end based on NEW billing cycle
if upgrade_data.billing_cycle == 'annual':
    sub.current_period_end = now + relativedelta(years=1)
```

**After (CORRECT):**
```python
# NOTE: period_end stays unchanged per document - customer pays prorated now, next cycle uses new billing_cycle
```

**Result:**
- `billing_cycle` updates immediately
- `period_end` stays unchanged
- Customer pays prorated amount now
- At renewal, invoice uses new billing_cycle price

---

### ✅ 5. Billing Cycle Change: annual → monthly (Scheduled via next_billing_cycle)

**File:** `website_api/app/models/models.py`

Added new field:
```python
next_billing_cycle = Column(String(20), nullable=True)  # For annual → monthly scheduled change at renewal
```

**Upgrade API Flow (annual → monthly):**
```python
if sub.billing_cycle == 'annual' and upgrade_data.billing_cycle == 'monthly':
    sub.next_billing_cycle = 'monthly'
    db.commit()
    return {
        "message": "Your billing cycle will change from annual to monthly at your next renewal date ({}). No charges applied now.".format(
            sub.current_period_end.strftime('%Y-%m-%d')),
        "next_billing_cycle": "monthly"
    }
```

**Renewal Cron Applies the Change:**
```python
# Check for scheduled billing cycle change (annual → monthly at renewal)
effective_billing_cycle = sub.billing_cycle
if sub.next_billing_cycle:
    effective_billing_cycle = sub.next_billing_cycle
    # Apply change
    sub.billing_cycle = sub.next_billing_cycle
    sub.next_billing_cycle = None  # Clear after applying
```

**Cancel Clears the Schedule:**
```python
# When subscription is cancelled
sub.next_billing_cycle = None  # Clear any scheduled billing change
```

## Implementation Details

### Database Changes

**Added Column:**
```sql
ALTER TABLE subscriptions ADD COLUMN next_billing_cycle VARCHAR(20);
```

### API Changes

**Subscription Response includes next_billing_cycle:**
```python
return {
    "billing_cycle": sub.billing_cycle,
    "next_billing_cycle": sub.next_billing_cycle,  # NEW
    "current_period_end": sub.current_period_end,
    ...
}
```

**Upgrade Response for annual → monthly:**
```python
return {
    "message": "Your billing cycle will change from annual to monthly at your next renewal date (2027-09-24). No charges applied now.",
    "billing_cycle": "annual",  # Unchanged
    "next_billing_cycle": "monthly",  # Scheduled
    "effective_date": "2027-09-24"  # When change applies
}
```

### Cron Job Changes

**In generate_renewal_invoices():**
```python
# Check for scheduled billing cycle change (annual → monthly at renewal)
effective_billing_cycle = sub.billing_cycle
if sub.next_billing_cycle:
    effective_billing_cycle = sub.next_billing_cycle
    print(f"  Applying billing cycle change: {sub.billing_cycle} → {effective_billing_cycle}")

# Create invoice with effective_billing_cycle price
amount = plan.price_monthly if effective_billing_cycle == 'monthly' else plan.price_annual

# ... create invoice ...

# Update subscription - apply billing cycle change and clear next_billing_cycle
sub.current_period_start = new_period_start
sub.current_period_end = new_period_end
if sub.next_billing_cycle:
    sub.billing_cycle = sub.next_billing_cycle
    sub.next_billing_cycle = None  # Clear after applying
```
