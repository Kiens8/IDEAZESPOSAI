# Language Switching System

**Date:** September 27, 2026

## Overview

This document outlines the language switching system to support 4 languages across the IDEAZES POS ecosystem:
- English (en)
- Chinese (zh) - 简体中文
- Malay (ms) - Bahasa Melayu
- Khmer (kh) - ភាសាខ្មែរ

---

## Languages Supported

| Code | Language | Display Name |
|------|----------|--------------|
| `en` | English | English |
| `zh` | Chinese | 简体中文 |
| `ms` | Malay | Bahasa Melayu |
| `kh` | Khmer | ភាសាខ្មែរ |

---

## Architecture

### Priority System

| App | Priority Order | Database |
|-----|---------------|----------|
| **Frontend POS** | User setting > Outlet setting > Default (en) | pos_ai.db |
| **Customer Order App** | User selection (stored in browser) > Outlet setting > Default (en) | pos_ai.db |
| **Site App** | User preference (localStorage) > Default (en) | website_api.db |

### Database Changes

#### pos_ai.db (Frontend POS & Customer Apps)

**outlet_settings Table**
```sql
ALTER TABLE outlet_settings ADD COLUMN language VARCHAR(10) DEFAULT 'en';
```

**users Table**
```sql
ALTER TABLE users ADD COLUMN language VARCHAR(10) DEFAULT NULL;
```

**customer_sessions Table**
```sql
ALTER TABLE customer_sessions ADD COLUMN language VARCHAR(10) DEFAULT NULL;
```

#### website_api.db (Site App)

Site app has its own database (`website_api.db`) for public-facing website.

### Date/Time & Currency Format

| App | Date/Time Format | Currency Format |
|-----|-----------------|----------------|
| **Frontend POS** | Follows outlet settings (timezone) | Follows outlet settings (currency_symbol) |
| **Customer Order App** | Follows outlet settings (timezone) | Follows outlet settings (currency_symbol) |
| **Site App** | Uses site's timezone setting | Uses site's currency setting |

*Note: These are already configured in outlet_settings table.*

### API Endpoints

#### PUT /api/users/{id}/password
Change user password.

**Request:**
```json
{
  "current_password": "string",
  "new_password": "string"
}
```

#### PUT /api/users/{id}/language
Update user language preference.

**Request:**
```json
{
  "language": "en|zh|ms|kh"
}
```

## Site App (Priority 3)

### Site App Structure

The Site App contains two parts:

| Part | Routes | Description |

## Menu Items & Categories Translation

### Approach: Manual Input via Menu Management

For menu items and categories (food names, descriptions), the system will allow manual translation input in the Menu Management screen.

### Menu Items - UI Design:
```
┌─────────────────────────────────────────┐
│ Item Name (English): [Pad Thai        ] │
│ Item Name (Chinese):  [泰式炒河粉       ] │
│ Item Name (Malay):   [Mie Goreng Siam ] │
│ Item Name (Khmer):   [ភេសជាតាខ្មែរ      ] │
│                                         │
│ Category: [Main Course ▼]               │
│ Price: [25.00                          │
└─────────────────────────────────────────┘
```

### Categories - UI Design:
```
┌─────────────────────────────────────────┐
│ Category Name (English): [Main Course  ] │
│ Category Name (Chinese):  [主菜           ] │
│ Category Name (Malay):   [Makanan Utama] │
│ Category Name (Khmer):   [ម្ហូបដ៏ធំ] │
└─────────────────────────────────────────┘
```

### Database Changes:

**menu_items Table:**
```sql
ALTER TABLE menu_items ADD COLUMN name_zh VARCHAR(255);
ALTER TABLE menu_items ADD COLUMN name_ms VARCHAR(255);
ALTER TABLE menu_items ADD COLUMN name_kh VARCHAR(255);
```

**categories Table:**
```sql
ALTER TABLE categories ADD COLUMN name_zh VARCHAR(255);
ALTER TABLE categories ADD COLUMN name_ms VARCHAR(255);
ALTER TABLE categories ADD COLUMN name_kh VARCHAR(255);
```

### Language Detection Logic (Display):

For both menu items and categories:
1. Check if user's language preference is set
2. If translation exists for that language, display it
3. Fallback to English if no translation

**Example Display Logic:**
```javascript
function getItemName(item, language) {
  switch(language) {
    case 'zh': return item.name_zh || item.name;
    case 'ms': return item.name_ms || item.name;
    case 'kh': return item.name_kh || item.name;
    default: return item.name;
  }
}
```

## Important Notes

### Database Separation

| App | Database | API |
|-----|----------|-----|
| Frontend POS | `pos_ai.db` | Backend API (port 8000) |
| Customer Order App | `pos_ai.db` | Backend API (port 8000) |
| Site App (Public + Portal) | `website_api.db` | Website API (port 9000) |

*Note: Each app has its own database and API. Translations for menu items and categories are stored in `pos_ai.db` (used by POS and Customer Apps). The Site App uses `website_api.db` for its public pages and customer portal.*
