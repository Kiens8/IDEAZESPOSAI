# AI Competitor Module

**Date:** September 25, 2026

## Overview

The AI Competitor module helps restaurants discover nearby competitors, build a competitor database, and analyze competitor menus/pricing using AI.

---

## Design Goals

| Goal | Description |
|------|-------------|
| **Competitor Discovery** | Find nearby restaurants within radius (1-5km) |
| **Competitor Database** | Save and manage competitor information |
| **Menu Intelligence** | AI-powered menu and price research |
| **Strategic Insights** | AI-generated recommendations based on market data |

---

## API Vendors

### Primary APIs

| API | Purpose | Pricing |
|-----|---------|---------|
| **Geoapify** | Restaurant discovery within radius | Free tier: 100,000 requests/month |
| **Overpass API (OSM)** | Fallback for restaurant data | Free, no restrictions |

### Secondary APIs (Optional Enhancement)

| API | Purpose | Pricing |
|-----|---------|---------|
| **Google Places** | Ratings, reviews, photos | ~$0.032/request |
| **Google Maps Geocoding** | Address to lat/lng conversion | Free tier available |

### Why This Combination?

```
Geoapify (Primary)
├── ✅ Free tier generous
├── ✅ Restaurant categories support
├── ✅ Easy to use
└── ✅ Good documentation

Overpass API (Fallback)
├── ✅ Completely free
├── ✅ No rate limits
└── ✅ Good for verification

Google Places (Enhancement)
├── ✅ Rich data (ratings, reviews)
├── ✅ Trusted source
└── ⚠️ Paid - use sparingly
```

## Database Schema

### New Table: `competitors`

```sql
CREATE TABLE competitors (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(255) NOT NULL,
    address TEXT,
    location_lat DECIMAL(10, 8),
    location_lng DECIMAL(11, 8),
    radius_km DECIMAL(5, 2),          -- Distance from user location
    api_source VARCHAR(50),             -- 'geoapify', 'overpass', 'manual'
    rating DECIMAL(2, 1),             -- 1.0 - 5.0 (if available)
    review_count INT,
    price_level VARCHAR(10),          -- '$', '$$', '$$$', '$$$$'
    cuisine_types JSON,               -- ['malaysian', 'chinese', 'western']
    phone VARCHAR(50),
    website VARCHAR(255),
    opening_hours JSON,
    menu_data JSON,                   -- Extracted menu items/prices
    menu_source VARCHAR(50),          -- 'ai_scraped', 'user_uploaded', 'manual'
    notes TEXT,
    is_saved BOOLEAN DEFAULT FALSE,
    outlet_id INT,                    -- For multi-outlet
    created_by INT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME ON UPDATE CURRENT_TIMESTAMP
);
```

### New Table: `competitor_menus`

```sql
CREATE TABLE competitor_menus (
    id INT PRIMARY KEY AUTO_INCREMENT,
    competitor_id INT,
    item_name VARCHAR(255),
    description TEXT,
    price DECIMAL(10, 2),
    category VARCHAR(100),
    is_ai_extracted BOOLEAN DEFAULT FALSE,
    source_url TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (competitor_id) REFERENCES competitors(id)
);
```

### API Integration

#### Geoapify API Call

```javascript
// Discover restaurants within radius
// Note: Use "catering.restaurant" category (commercial.restaurant is not supported)
const response = await fetch(
  `https://api.geoapify.com/v2/places?` +
  `categories=catering.restaurant` +
  `&filter=circle:${longitude},${latitude},${radiusInMeters}` +
  `&limit=50` +
  `&apiKey=${GEOAPIFY_API_KEY}`
);

const results = response.data.features.map(f => ({
  name: f.properties.name,
  address: f.properties.address_line1,
  location: { lat: f.geometry.coordinates[1], lng: f.geometry.coordinates[0] },
  distance: f.properties.distance,
  categories: f.properties.categories,
  rating: f.properties.rating,
  reviews: f.properties.reviews
}));
```

#### Overpass API Fallback

```javascript
// Overpass QL query
const query = `
  [out:json][timeout:25];
  (
    node["amenity"="restaurant"](around:3000,${lat},${lng});
    way["amenity"="restaurant"](around:3000,${lat},${lng});
  );
  out body;
  >;
  out skel qt;
`;

// Fetch and parse
const response = await fetch(
  `https://overpass-api.de/api/interpreter?data=${encodeURIComponent(query)}`
);
```

### Geoapify vs Overpass Strategy

```javascript
async function discoverCompetitors(lat, lng, radiusKm) {
  // Try Geoapify first
  try {
    const geoapifyResults = await geoapifySearch(lat, lng, radiusKm);
    if (geoapifyResults.length > 0) {
      return geoapifyResults;
    }
  } catch (e) {
    console.log('Geoapify failed, trying Overpass...');
  }
  
  // Fallback to Overpass
  const overpassResults = await overpassSearch(lat, lng, radiusKm);
  return overpassResults;
}
```

## Competitor Analysis Tab (Enhanced)

### User Flow

```
1. User selects from saved competitors (checkboxes)
2. User clicks "AI Search Menu"
3. AI scrapes/grabs menu from web
4. AI analyzes menu items and prices
5. AI generates comparison report
6. User can export or save analysis
```

### AI Menu Search Feature

```javascript
// AI Search Menu for selected competitors
async function searchCompetitorMenus(competitorIds) {
  const competitors = await getCompetitorsByIds(competitorIds);
  
  for (const competitor of competitors) {
    // AI searches web for menu information
    const menuData = await ai.grabMenuFromWeb({
      name: competitor.name,
      website: competitor.website,
      location: competitor.address
    });
    
    // AI extracts menu items and prices
    const extractedItems = menuData.items.map(item => ({
      name: item.name,
      price: item.price,
      category: item.category
    }));
    
    // Save to database
    await saveCompetitorMenu(competitor.id, extractedItems);
  }
}
```

## API Endpoints

### Competitor Discovery

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/competitors/discover` | Discover nearby competitors |
| GET | `/api/competitors/nearby` | Get saved nearby competitors |

### Competitor Management

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/competitors` | List all saved competitors |
| POST | `/api/competitors` | Save competitor |
| GET | `/api/competitors/{id}` | Get competitor details |
| PUT | `/api/competitors/{id}` | Update competitor |
| DELETE | `/api/competitors/{id}` | Delete competitor |

### Menu Analysis

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/competitors/{id}/menu/search` | AI search for menu |
| GET | `/api/competitors/{id}/menu` | Get competitor menu |
| POST | `/api/competitors/compare` | Compare with your restaurant |

### Reports

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/competitors/{id}/report` | Get analysis report |
| POST | `/api/competitors/report` | Generate bulk report |

```
Analyze this restaurant and provide strategic insights:

Restaurant: {name}
Address: {address}
Categories: {cuisine_types}
Rating: {rating} ({review_count} reviews)
Distance: {distance}km

Provide:
1. Market positioning (1 sentence)

#### Menu Extraction Prompt
```
Extract menu items from this restaurant information:

Restaurant: {name}
Web content: {web_content}

Return a JSON array of menu items with:
- item_name
- price (if found)
- category (if found)
- description (optional)
```

#### Comparison Prompt
```
Compare these two restaurants and provide insights:

MY RESTAURANT:
- Name: {my_name}

COMPETITOR:
- Name: {competitor_name}

Provide:

## Error Handling

| Scenario | Handling |
|----------|----------|
| Geoapify API fails | Fallback to Overpass API |
| Overpass fails | Show error, allow manual entry |
| No competitors found | Show "No restaurants found" message |
| AI analysis fails | Show basic info, retry option |
| Rate limit hit | Queue requests, show user message |

---

## Security & Privacy

| Concern | Mitigation |
|---------|-------------|
| API keys exposed | Store in backend env, not frontend |
| Competitor data | Only public info stored |
| User location | Use POS location, encrypt in transit |
| Rate limiting | Implement request throttling |
