# Quick Start Guide

Get your restaurant up and running with IDEAZES POS AI in just a few minutes.

## Prerequisites

- A device (tablet, computer, or smartphone)
- Internet connection
- A IDEAZES POS AI account with active subscription

## Step 1: Log In

1. Go to [app.ideazes.com](https://app.ideazes.com)
2. Enter your email and password
3. Click **Sign In**

## Step 2: Select Outlet

If you have multiple outlets, select the outlet you want to work with from the dropdown menu.

## Step 3: Start Taking Orders

### For Counter Service Restaurants

1. Click **New Order** on the dashboard
2. Search or browse menu items
3. Add items to the order
4. Click **Record Payment** when ready
5. Print receipt (if configured)

### For Table Service Restaurants

1. Select a table
2. Add items to the order
3. Update order status as needed:
   - **Pending** → **Confirmed** → **Preparing** → **Ready** → **Served**
4. Click **Record Payment** after serving
5. Print receipt (if configured)

## Step 4: View Reports

Access reports from the dashboard to track:
- Daily sales
- Popular items
- Staff performance
