## Backend Changes

### 1. Period Extension Removed

File: website_api/app/routes/webhooks.py

Payment no longer extends subscription period. Period end date stays fixed until renewal.

### 2. Invoice Status Values

File: website_api/app/models/models.py

Values: pending, paid, failed, forgiven, refunded, cancelled

Note: Trial is NOT a valid invoice status. Trial invoices have status pending.

### 3. Renewal Invoice Generation

File: website_api/scripts/send_notifications.py

Creates new invoice at period end for active subscriptions.

### 4. Trial End Processing

File: website_api/scripts/send_notifications.py

Processes trial endings and generates first paid invoice.

### 5. Cancelled Access Check

File: backend/app/routes/auth.py

Cancelled subscriptions block access after period_end.
