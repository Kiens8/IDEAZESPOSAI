## Change 1: Remove Period Extension on Payment

### File

website_api/app/routes/webhooks.py

### Before

Payment extended subscription period when invoice was paid.

### After

Period extension removed. Period end date stays fixed until renewal at period end.

---

## Change 2: Invoice Status Values

### File

website_api/app/models/models.py

### Values

pending, paid, failed, forgiven, refunded, cancelled

Note: Trial is NOT a valid invoice status. Trial invoices have status pending with description Trial Period.

## Backend Fix: Cancelled Subscription Access Check

### File

backend/app/routes/auth.py

### Logic

Cancelled subscriptions:
- If now <= period_end: ALLOW access
- If now > period_end: BLOCK access (status stays cancelled)

This ensures cancelled subscriptions are blocked after period ends.
