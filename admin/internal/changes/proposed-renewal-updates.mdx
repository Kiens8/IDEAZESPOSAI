## 2. Invoice Status - No "trial" Status

### Current Implementation

Invoice model has `status = Column(String(50), default="pending")` with values including "trial"

### New Design

Invoice statuses are: `pending`, `paid`, `failed`, `forgiven`, `refunded`, `cancelled`

**Invoice knows it's a trial based on:**
- Plan description (e.g., "Trial Period - 30 days")
- Subscription status (checked separately)

### Proposed Change

**File:** `website_api/app/models/models.py`

```python
# Current (WRONG):
status = Column(String(50), default="pending")
# Values: pending, paid, failed, forgiven, refunded, cancelled, trial  # REMOVE 'trial'

# Correct values:
status = Column(String(50), default="pending")
# Values: pending, paid, failed, forgiven, refunded, cancelled
```

**Trial invoice creation should:**
1. Create invoice with `status = 'pending'`
2. Set `description` = "Trial Period - 30 days" (or similar)
3. Cron job marks as `paid` (same as free plan)

## 3. Cron Job: Generate New Invoice at Period End

### Current Implementation Gap

The cron job currently:
- ✅ Checks expired subscriptions
- ✅ Sends warning emails
- ✅ Marks forgiven invoices

**Missing:**
- ❌ Does NOT generate new invoice at period end for recurring billing

### New Design

At period end (Day 30, Day 60, etc.):

1. Create new invoice for next billing cycle
2. Set invoice `due_date` = `period_end + payment_due_days` (grace period)
3. Subscription continues as active (no status change needed)

### Proposed Addition

**File:** `website_api/scripts/send_notifications.py`

Add new function:

```python
def generate_renewal_invoices(db: Session):
    """
    Generate new invoices for subscriptions reaching period end.
    
    Per renewal system design:
    - At period end, new invoice is created for next cycle
    - Subscription continues as active
    - Invoice due_date = period_end + grace_period (14 days)
    """
    print("\n" + "="*60)
    print("RENEWAL INVOICE GENERATION")
    print("="*60)
    
    from dateutil.relativedelta import relativedelta
    from app.models.models import Subscription, SubscriptionPlan, Invoice
    import secrets
    
    # Find active subscriptions where period_end has passed
    expired_periods = db.query(Subscription).filter(
        Subscription.status == 'active',
        Subscription.current_period_end <= datetime.utcnow()
    ).all()
    
    invoice_count = 0
    
    for sub in expired_periods:
        # Get plan details
        plan = db.query(SubscriptionPlan).filter(
            SubscriptionPlan.id == sub.plan_id
        ).first()
        
        if not plan:
            continue
        
        # Calculate amount based on billing cycle
        amount = plan.price_monthly if sub.billing_cycle == 'monthly' else plan.price_annual
        
        # Skip if $0 (free plan)
        if amount == 0:
            # For free plans, just extend the period
            if sub.billing_cycle == 'monthly':
                sub.current_period_end = sub.current_period_end + relativedelta(months=1)
            else:
                sub.current_period_end = sub.current_period_end + relativedelta(years=1)
            db.commit()
            print(f"  ✓ Extended free plan subscription {sub.id} to {sub.current_period_end}")
            continue
        
        # Get grace period from settings
        grace_days = 14  # default
        try:
            from app.routes.admin import get_setting_value
            grace_days = int(get_setting_value(db, "payment_due_days", "14"))
        except:
            pass
        
        # Create new invoice for next period
        new_period_start = sub.current_period_end
        if sub.billing_cycle == 'monthly':
            new_period_end = sub.current_period_end + relativedelta(months=1)
        else:
            new_period_end = sub.current_period_end + relativedelta(years=1)
        
        invoice = Invoice(
            customer_id=sub.customer_id,
            subscription_id=sub.id,
            invoice_number=f"INV-{datetime.utcnow().strftime('%Y%m%d')}-{secrets.token_hex(4).upper()}",
            amount=amount,
            currency='USD',
            status='pending',
            payment_method=sub.payment_method or 'pay_later',
            due_date=new_period_start + timedelta(days=grace_days),
            description=f"Recurring subscription - {sub.billing_cycle}"
        )
        db.add(invoice)
        
        # Update subscription period
        sub.current_period_start = new_period_start
        sub.current_period_end = new_period_end
        
        invoice_count += 1
        print(f"  ✓ Generated invoice for subscription {sub.id}, due {invoice.due_date}")
    
    db.commit()
    print(f"\nRenewal invoices generated: {invoice_count}")
    return invoice_count
```

def mark_zero_invoices_paid(db: Session):
    """
    Mark $0 invoices as paid (free plans and trial).
    Per renewal system: cron job auto-marks these as paid.
    """
    print("\n" + "="*60)
    print("ZERO INVOICE AUTO-PAID")
    print("="*60)
    
    zero_invoices = db.query(Invoice).filter(
        Invoice.status == 'pending',
        Invoice.amount == 0
    ).all()
    
    count = 0
    for invoice in zero_invoices:
        invoice.status = 'paid'
        invoice.paid_at = datetime.utcnow()
        count += 1
    
    db.commit()
    print(f"Invoices marked as paid: {count}")
    return count
