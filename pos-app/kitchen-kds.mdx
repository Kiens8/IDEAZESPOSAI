# Kitchen Display System (KDS)

The Kitchen Display System provides real-time order management for kitchen staff, with automatic notifications, ticket printing, and order reminders.

## Overview

When orders are placed through the POS or online ordering system, they appear instantly on the Kitchen Display screen. Kitchen staff can:

- View incoming orders in real-time
- Update order status (Confirm → Preparing → Ready)
- Receive sound notifications for new orders
- Receive urgent reminders for orders waiting too long
- Print kitchen tickets to any configured printer type

## How It Works

### Order Flow

```
1. Order Placed (POS / Online)
         ↓
2. Kitchen Display receives order (auto-refresh every 3 seconds)
         ↓
3. Sound notification plays (if enabled)
         ↓
4. Kitchen staff sees order card on screen
         ↓
5. Staff clicks "Confirm Order"
         ↓
6. Staff clicks "Start Preparing"
         ↓
7. Staff clicks "Mark Ready" → Order stays visible
         ↓
8. Staff marks "Served" → Order disappears
```

### Order Statuses

| Status | Description | Color |
|--------|-------------|-------|
| **Pending** | New order, not yet confirmed | Yellow |
| **Confirmed** | Order confirmed by kitchen | Blue |
| **Preparing** | Kitchen is preparing the order | Orange |
| **Ready** | Order ready for service, waiting to be served | Green |

**Important:** "Ready" orders stay on screen until staff marks them as "Served". They do not auto-dismiss.

## Order Reminders

When orders have been waiting too long (pending/confirmed status), the system provides visual and audio alerts:

### How Reminders Work

1. **Countdown Timer** - Each order card shows a countdown timer (e.g., "⏱️ 1:45")
2. **Visual Alert** - When countdown reaches final minute, order card gets:
   - Red warning border
   - Pulsing animation
   - "⚠️ REMINDER" badge
3. **Alert Sound** - Plays urgent reminder sound (different from new order sound)

### Reminder Behavior

- Reminder countdown uses **Order Reminder setting** (default: 5 minutes)
- Countdown resets after each cycle
- Sound plays **once per cycle** when entering the final minute (e.g., at 4:00 for a 5-minute cycle)
- Reminder continues until order status changes to "preparing" or higher

### Example with 5-minute Reminder

| Time | Countdown | Action |
|------|-----------|--------|
| 0:00 | 5:00 | Order appears, countdown starts |
| 4:00 | 1:00 | 🔔 **SOUND PLAYS** (entering final minute) |
| 5:00 | 5:00 | Countdown resets (new cycle starts) |
| 9:00 | 1:00 | 🔔 **SOUND PLAYS AGAIN** |
| 10:00 | 5:00 | Countdown resets, new cycle |

## Settings

Configure the Kitchen Display in **Settings → Kitchen** tab:

### Order Reminder (minutes)

**Purpose:** Time before showing reminder alert.

- **Range:** 1-30 minutes
- **Default:** 5 minutes
- **Behavior:** After this time, pending/confirmed orders show countdown and reminder alerts
- **Effect:** Order card shows countdown timer, then red border and sound when entering final minute

### Sound Notifications

**Purpose:** Play a sound alert when new orders arrive.

- **Default:** Enabled
- **Toggle:** On/Off switch in Kitchen settings
- **Manual Mute:** Click sound icon on Kitchen page to temporarily mute

### Auto-Print Kitchen Tickets

**Purpose:** Automatically print kitchen tickets when orders arrive.

- **Default:** Disabled
- **Printer:** Uses network printer configured in Receipt settings
- **Requirement:** Only works when Receipt Printer Type is set to "Network"
- **Ticket Format:** Simplified order ticket (no prices, just items)

**Note:** Auto-print is only available for network printers. For other printer types (Quick Print, PDF, Screenshot), use the **Manual Print button** on each order card.

## Kitchen Ticket Printing

### Manual Print Button

Kitchen staff can manually print tickets by clicking the 🖨️ button on any order card.

**Works with ALL printer types** configured in Receipt settings:

| Printer Type | Behavior |
|-------------|----------|
| **Network** | Sends ticket directly to network printer |
| **Quick Print** | Opens browser print dialog |
| **PDF** | Opens PDF preview for printing |
| **Screenshot** | Captures ticket as image |

### Auto-Print vs Manual Print

| Feature | Auto-Print | Manual Print Button |
|---------|------------|---------------------|
| **Printer Type** | Network only | All types |
| **Trigger** | Automatic on new order | Staff clicks button |
| **Use Case** | Busy kitchen, hands-free | When needed |

## Kitchen Ticket Format

Kitchen tickets include:

```
       *** KITCHEN ***
           
         #12345
    --------------------------------
    [DINE IN] 10:30 AM Table 5
    --------------------------------
    
    2x Burger
       > No onions
       > Extra cheese
    
    1x Fries
       > Extra salt
    
    1x Coke
    --------------------------------
```

**Note:** Datetime on kitchen tickets uses the outlet's timezone setting.

## Timezone Handling

Kitchen Display correctly handles timezones:

- **Order Numbers:** Date portion uses outlet timezone
- **Kitchen Tickets:** Datetime uses outlet timezone
- **Order History:** Date filtering uses outlet timezone

Configure timezone in **Settings → General → Timezone**.

## Printer Requirements

### For Network Printing

Kitchen tickets use ESC/POS commands and require:

1. **Network Thermal Printer** (recommended)
2. **Browser Print Server** Chrome extension (optional)
3. Printer must be connected to the same network as the POS device

### Supported Printers

Most thermal printers with network capability:

- Epson TM-T88 series
- Star TSP series
- Any ESC/POS compatible printer

## Troubleshooting

### No Sound Notifications

1. Check that "Sound notifications" is enabled in Settings → Kitchen
2. Click the sound icon on Kitchen page to check if manually muted
3. Ensure browser allows audio/autoplay

### Tickets Not Printing (Network)

1. Verify printer IP is configured in Settings → Receipt → Network Printer
2. Check printer is powered on and connected to network
3. Try printing a test page from printer settings
4. Install Browser Print Server extension for reliability

### Tickets Not Printing (Manual Print)

1. Check Receipt Printer Type in Settings → Receipt
2. Verify printer is configured correctly
3. For Quick Print - ensure browser print dialog appears

### Orders Not Appearing

1. Verify Kitchen page is open in browser
2. Check refresh interval (auto-refresh every 3 seconds)
3. Click "Refresh" button to manually reload
4. Check if orders are in correct status (pending/confirmed/preparing/ready)

### Ready Orders Not Showing

- "Ready" orders stay on screen until served
- Check if the order was marked as "Served"
- Ready orders do not auto-dismiss

### Reminder Sound Not Playing

- Reminder sound plays only once per cycle when entering final minute
- After playing, sound won't play again until the next cycle
- This is intentional to avoid annoying repeated sounds

### Date/Time Issues

If dates appear incorrect:
1. Check outlet timezone setting in Settings → General → Timezone
2. Verify server timezone matches expected location
3. Kitchen tickets and order numbers use outlet timezone
