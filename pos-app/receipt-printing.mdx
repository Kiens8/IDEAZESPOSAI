# Receipt printing

The POS prints receipts on the printer you set up for the branch. The printer is set on the **Settings** screen, on the **Receipt** tab, and only an admin can change it.

## The five printer choices

The **Printer Type** radio group offers five options.

| Option | What it does | What you need |
|---|---|---|
| **None (No Printer)** | Receipt printing disabled | Nothing |
| **Quick Print (Browser Print)** | Uses your default printer via browser | A printer set up in the browser |
| **Network Printer (ESC/POS)** | Direct print to network thermal printer | ⚠️ Requires: Browser Print Server (Chrome extension) |
| **Bluetooth Printer** | Print via Bluetooth (Chrome/Edge only) | ⚠️ Requires: Chrome/Edge browser + Bluetooth pairing |
| **PDF / Screenshot** | Save receipt as PDF or image | Nothing |

If nothing is stored yet, **None (No Printer)** is the option that is ticked.

## Setting up your printer

Open **Settings**, then the **Receipt** tab, and find the **Receipt Printer** section.

### Quick Print

Choose **Quick Print (Browser Print)** and press **Save Settings**. The POS then opens the browser's own print window when a receipt is printed, and you pick the printer there.

### Network printer

Choose **Network Printer (ESC/POS)** and two extra fields appear:

| Setting | What you put in it | Default |
|---|---|---|
| **Printer IP Address** | The printer's IP address on your network | Empty |
| **Port** | The port the printer listens on | `9100` |

### Bluetooth printer

Choose **Bluetooth Printer** and a **Bluetooth Device** dropdown appears. Its first option is **Select a device...** and the rest come from the devices already paired to the branch.

A note under the field reads **Note: Bluetooth requires Chrome or Edge browser**.

<Note>
**Test Connection** and **Scan** do nothing yet. They only show a message that the feature is coming soon. **Test Connection** does not test your network printer, and **Scan** does not look for Bluetooth devices, so the **Bluetooth Device** list stays empty until a device is paired another way.
</Note>

## Printing a receipt after a payment

When you record a payment for an order, a **Print Receipt** banner appears on the Orders screen. Press it and the receipt goes to the printer you configured.

The receipt carries the wording you set on the **Receipt** tab: **Receipt Header**, **Receipt Footer**, **Terms & Conditions** and **Return/Refund Policy**. The time printed on it comes from the branch timezone, so it is your local time even if the terminal is somewhere else.

## How many copies

Set **Receipt Copies** on the **Receipt** tab. It offers **1 Copy**, **2 Copies** and **3 Copies**. The default is **1**.

When you reprint an order from **Order History**, the reprint dialog asks how many copies to print as well, along with whether the pickup token goes on the paper and an optional reason.

<Note>
Only a paid order can be reprinted. If the branch has no printer configured, the dialog says **This outlet has no receipt printer configured. Set one up in the outlet settings.** and the **Print** button stays disabled.
</Note>

## Kitchen tickets

The **Auto-print kitchen tickets** switch on the **Kitchen** tab prints a ticket for every new order. It uses the receipt printer you configured, so the two have to agree.

| Printer type | Auto-prints a kitchen ticket? |
|---|---|
| **Quick Print (Browser Print)** | Yes |
| **Network Printer (ESC/POS)** | Yes |
| **PDF / Screenshot** | Yes |
| **Bluetooth Printer** | No |
| **None (No Printer)** | No |

The ticket only prints for **new** orders that arrive while the kitchen screen is open. Orders already on screen are not reprinted.

<Note>
With **Bluetooth Printer** selected, **Auto-print kitchen tickets** does nothing and says nothing. There is no ticket and no warning, so print the ticket yourself with the manual button on the order.
</Note>

## Network printing from the browser

A network printer reaches the POS over your network, and the POS needs the browser print bridge to talk to it. The option is labelled **Network Printer (ESC/POS)** with the warning **⚠️ Requires: Browser Print Server (Chrome extension)**.

The reprint dialog repeats it in plain words: **This outlet uses a network printer. It only works through the Browser Print Server bridge - from the browser it will fail.**

So a network printer set up in the POS without that bridge in place will not print from the browser.

## Bluetooth printing

Bluetooth printing works in Chrome and Edge. It does not work in Safari or Firefox, so open the POS in Chrome or Edge on the counter device when you use a Bluetooth printer.
