# site.app - Landing Page

The landing page at **site.ideazes.com** is the marketing website where potential customers learn about IDEA ZeroS POS AI and sign up for a free trial.

## Features

### Public Pages
- **Hero Section** - Introduction to IDEA ZeroS POS AI
- **Features Overview** - Key capabilities of the system
- **Pricing Display** - Available subscription plans
- **Free Trial Signup** - Create new customer account

### Customer Flow
1. Customer visits site.ideazes.com
2. Views features and pricing
3. Signs up for free trial
4. Account created in the system
5. Redirected to order.app for setup
