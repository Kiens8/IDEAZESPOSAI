## Feature Updates

### 1. Email Verification Status Fix (Bug Fix)
**Issue:** Email verification status not updating after clicking verify link  
**Fix:** Changed API endpoint from `/api/auth/profile` to `/api/auth/me`  
**File:** `/root/.openclaw/workspace/mydoc/Projects/POS_AI/site/src/app/portal/page.tsx`

### 2. Feature Lock Before Email Verification
**Implementation:** When email is NOT verified:
- Open POS button → Locked ("Verify email to access")
- Upgrade Plan button → Locked ("Verify email to upgrade")
- View Invoices button → Locked ("Verify email to view")
- Subscription Tab → Shows "🔒 Email Verification Required" with Resend button

### 3. Subscription Wizard (3-Step Flow)
**Step 1: Select Plan**
- Plan cards (Starter, Basic, Pro, Enterprise)
- Billing cycle toggle (Monthly / Annual - Save 20%)
- Next button (enabled when plan selected)

**Step 2: Choose Option**
- "Start 30-Day Free Trial" option (hidden for $0 plans)
- "Subscribe Now" option
- Back/Next navigation

**Step 3: Payment Method**
- Order Summary display
- "Pay Later" option
- "Credit/Debit Card (Stripe)" option
- "Confirm Subscription" button

### 4. Stripe Checkout Integration
**Endpoint:** `POST /api/subscriptions/create` (unified endpoint)  
**Request Body:**
```json
{
  "plan_id": 1,
  "billing_cycle": "monthly",
  "choice": "trial" | "subscribe",
  "payment_method": "stripe" | "pay_later"
}
```

**Behavior:**
- **$0 transactions** (Trial or $0 plan): Creates subscription + invoice immediately, no Stripe redirect
- **Paid plans**: Creates pending invoice + returns Stripe checkout URL

**Success URL:** `https://site.ideazes.com/portal?checkout=success`  
**Cancel URL:** `https://site.ideazes.com/portal?checkout=canceled`

### 5. Bug Fix: Billing Cycle Selection
**Issue:** Changing billing cycle didn't reset choice selection  
**Fix:** When changing billing cycle, `choice` is now reset to `null`

### 6. Unified Subscription Creation Endpoint
**New Endpoint:** `POST /api/subscriptions/create`

**Flow:**
| Scenario | Invoice | Cron Job | Stripe |
|----------|---------|----------|--------|
| $0 (Trial/Starter) | ✅ Created (pending) | ✅ Marks paid | ❌ Skipped |
| Paid (Pro/Enterprise) | ✅ Created (pending) | ✅ Marks paid | ✅ Redirected |

This aligns with the documented renewal system where cron job handles $0 invoice status updates.

## API Endpoints Used

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/auth/me` | Get user profile including email_verified status |
| GET | `/api/subscriptions/current` | Get current subscription |
| POST | `/api/subscriptions/create-checkout` | Create Stripe checkout session |
| POST | `/api/auth/resend-verification` | Resend verification email |
