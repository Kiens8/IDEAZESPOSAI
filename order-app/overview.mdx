# Customer App - Customer Ordering

The customer ordering app at **order.ideazes.com** allows customers to browse menus and place orders online.

## Features

### For Customers
- **QR Code Ordering** - Scan table QR code to view menu and order
- **Menu Browsing** - View categories, items, and modifications
- **Cart Management** - Add/remove items, modify orders
- **Order Tracking** - Real-time order status updates
- **Payment** - Online payment for orders

### Order Flow
1. Customer scans QR code or visits order.ideazes.com
2. Selects items and customizations
3. Submits order
4. Payment processed
5. Order sent to POS kitchen display
6. Customer receives status updates

## Key Concepts

### Table Management
- Each table has a unique QR code
- QR codes link to specific outlet and table
- Customers can order without waitstaff

### Menu Integration
- Menu synced from POS backend
- Real-time menu updates
- Item availability based on outlet settings
