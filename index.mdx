# Welcome to IDEAZES POS AI

IDEAZES POS AI is a next-generation cloud-based restaurant management system that goes beyond traditional POS — powered by AI tools to help your business make smarter decisions and grow faster.

Unlike conventional POS systems, IDEAZES POS AI integrates intelligent AI tools that analyze your data, track competitors, create smart campaigns, and engage customers — so you can focus on what matters most: serving your customers.

---

## System Overview

The IDEAZES system consists of 6 interconnected applications:

| App | URL | Purpose |
|-----|-----|---------|
| **Site** | site.ideazes.com | Landing page & marketing |
| **admin.app** | admin.ideazes.com | Management panel (internal) |
| **POS Frontend** | app.ideazes.com | POS terminal for staff |
| **Customer App** | order.ideazes.com | Customer online ordering |
| **api.ideazes.com** | POS Backend API | Order processing & data |
| **apisite.ideazes.com** | Website API | Subscriptions & billing |

## AI Tools

IDEAZES POS AI comes with powerful AI tools designed for restaurants:

| Tool | Description |
|------|-------------|
| **AI Insights** | Get smart recommendations based on your business data |
| **AI Menu Analytics** | Analyze menu performance and optimize pricing |
| **AI Campaigns** | Create intelligent marketing campaigns automatically |
| **AI Competitor Analytics** | Monitor and analyze competitor activities |
| **AI Chatbot** | Engage customers and handle inquiries 24/7 |

## Key Features

- **Intelligent Order Management** — Track orders from pending to payment
- **Smart Receipt Printing** — Print via browser, network, or Bluetooth
- **Kitchen Display (KDS)** — Real-time synchronized kitchen operations
- **QR Ordering** — Customer self-ordering via QR codes
- **Flexible Plans** — From free to enterprise
- **Multi-Outlet Support** — One dashboard for all locations
- **Cloud-Based** — Access anywhere, anytime
