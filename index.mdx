# Welcome to IDEA ZeroS POS AI Documentation

IDEA ZeroS POS AI is a comprehensive point-of-sale and online ordering system designed for restaurants and food businesses.

## System Overview

The IDEAZES system consists of 6 interconnected applications:

| App | URL | Purpose |
|-----|-----|---------|
| **site.app** | site.ideazes.com | Landing page & marketing |
| **admin.app** | admin.ideazes.com | Management panel (internal) |
| **pos.app** | app.ideazes.com | POS terminal for staff |
| **order.app** | order.ideazes.com | Customer online ordering |
| **api.ideazes.com** | POS Backend API | Order processing & data |
| **apisite.ideazes.com** | Website API | Subscriptions & billing |

## Key Features

- **POS Terminal** - Fast order processing, receipt printing, kitchen display
- **Kitchen Display** - Real-time order management for kitchen staff
- **QR Ordering** - Customer self-ordering via QR codes
- **Subscription Plans** - Tiered pricing with feature limits
- **Multi-Outlet** - Manage multiple restaurant locations
