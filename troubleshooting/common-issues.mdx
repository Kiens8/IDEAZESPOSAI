# Common Issues

Quick solutions to frequent problems.

## Login Issues

### Can't Log In

**Symptoms:** Incorrect password error

**Solutions:**
1. Check Caps Lock is off
2. Reset password using "Forgot Password"
3. Contact admin to reset your account

### Session Expired

**Symptoms:** Redirected to login page

**Solutions:**
1. Clear browser cache
2. Check internet connection
3. Try incognito/private window

## Receipt Printing Issues

### Quick Print Not Working

**Symptoms:** Nothing happens when clicking Print Receipt

**Solutions:**
1. Check default printer is set in browser
2. Allow pop-ups for POS AI site
3. Ensure printer is powered on and connected

### Network Printer Not Connecting

**Symptoms:** "Connection failed" error

**Solutions:**
1. Verify printer IP address is correct
2. Ensure printer is on same network
3. Check firewall settings
4. Try installing Browser Print Server extension

### Bluetooth Not Detecting

**Symptoms:** No devices found

**Solutions:**
1. Ensure printer is in pairing mode
2. Use Chrome or Edge browser (not Safari/Firefox)
3. Grant Bluetooth permissions when prompted
4. Try turning Bluetooth off/on

## Order Management Issues

### Order Not Appearing

**Symptoms:** New order doesn't show in queue

**Solutions:**
1. Refresh the page
2. Check you're in the correct outlet
3. Contact admin to verify permissions

### Can't Update Order Status

**Symptoms:** Status button not working

**Solutions:**
1. Refresh the page
2. Clear browser cache
3. Check internet connection

## Payment Issues

### Payment Failed

**Symptoms:** "Payment failed" error

**Solutions:**
1. Check card details are correct
2. Ensure sufficient funds
3. Try a different payment method
4. Contact your bank

### Invoice Not Received

**Symptoms:** Email not received for Pay Later

**Solutions:**
1. Check spam/junk folder
2. Verify email address is correct
3. Contact support if issue persists
